# nabla.js

A Mathematics and Computer Science educational library.

The purpose is to make a bug-free, concise, no dependencies, clear implementation of mathematical/computer science concepts.

# nabla.js programs

- Dynamic contiguous array
- Hash table
- Linked list
- Stack
- Queue
- Set
- Monads
    - Maybe
    - Try monad
- Priority queue
- Self-balancing binary tree
- Graph
- Simplicial complexes / Half-edge data structure
- Linear algebra
- ODE solvers
- Geometric algebra
- Tensors (up | down)
- Differential programming / automatic differentiation
- Symbolic computation
- Parser of parsers
- Machine learning algorithms
    - Linear regression
    - Logistic regression
    - Deep neural networks
    - K-means clustering
    - PCA
    - SVM
    - Manifold learning algorithms
